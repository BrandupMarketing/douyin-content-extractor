# Douyin Content Extractor

抖音内容提取 - 一键安装，直接使用

---

## 一键安装

```bash
curl -L -o install.sh "https://raw.githubusercontent.com/BrandupMarketing/douyin-content-extractor/main/install.sh" && bash install.sh
```

安装三个组件：
1. **gstack-browse** - 浏览器工具
2. **Douyin API** - 抖音后端 API
3. **douyin-extractor** - 提取技能

---

## 使用方法

安装后，直接给我抖音链接就能提取！

支持：
- 抖音短链接 (v.douyin.com/xxx)
- 抖音视频 ID
- 无水印视频下载
